1. **Workflow Builder Agent**
2. **Insights Inteligentes Agent**
3. **Monitor de Gargalos Agent**

❗ Não alterar UX, endpoints ou comportamentos originais.

# 🔧 O que implementar (passo a passo)

---

## 1. Criar estrutura LangChain/LangGraph/LangSmith

Criar a pasta:

```
server/ai/lc/
  agents/
    base-agent.ts
    workflowBuilder.ts
    insights.ts
    bottleneckDetector.ts
  graphs/
    agentGraph.ts
    index.ts
```

---

## 2. Criar `BaseAgent` (fundamental)

Em `server/ai/lc/agents/base-agent.ts`:

- Criar classe `BaseAgent`
- Construtor recebe:
  - name
  - systemPrompt
  - model (OpenAI)
- Criar RunnableSequence dentro da classe
- Incluir:
  - LangSmith tracing (`withConfig({ runName })`)
  - Formatação de input/output
  - Método `async run(input: any)`

---

## 3. Criar subclasses para os 3 agentes

Criar:

### workflowBuilder.ts
- Importar BaseAgent
- Manter o prompt do agente original
- Output deve continuar sendo:
  ```json
  {
    "area": "",
    "etapas": [],
    "regras": [],
    "criticidade": ""
  }
  ```

### insights.ts
- Manter lógica existente
- Transformar em RunnableSequence
- Output deve ser lista de insights em JSON

### bottleneckDetector.ts
- Analisar workflow + demandas
- Retornar lista de gargalos
- Usar BaseAgent + RunnableSequence

❗ Preserve prompts e comportamento.  
❗ Apenas troque engine → LangChain.

---

## 4. Criar LangGraph com 3 nós

Criar arquivo `server/ai/lc/graphs/agentGraph.ts`

O grafo deve conter:

- Nó `workflowBuilder`
- Nó `insights`
- Nó `bottleneck`

Fluxo:

```
workflowBuilder → insights → bottleneck
```

StateGraph deve receber:

```ts
{
  demand: string;
  workflow?: any;
  insights?: any;
  bottlenecks?: any;
}
```

---

## 5. Criar endpoint unificado `/api/ai/graph`

Criar:

```
POST /api/ai/graph
```

Entrada:

```json
{
  "demand": "texto da demanda"
}
```

Fluxo do endpoint:

1. Chamar o grafo
2. Executar os 3 agentes via LangGraph
3. Logar execução no LangSmith
4. Retornar JSON final:

```json
{
  "workflow": {...},
  "insights": [...],
  "bottlenecks": [...]
}
```

---

## 6. Integrar LangSmith (obrigatório)

Usar:

```ts
import { traceable } from "@langchain/core/tracers";
```

Cada agente deve aparecer no LangSmith como:

- Run completo (não “incomplete”)
- Com nome do agente
- Com input/output renderizado
