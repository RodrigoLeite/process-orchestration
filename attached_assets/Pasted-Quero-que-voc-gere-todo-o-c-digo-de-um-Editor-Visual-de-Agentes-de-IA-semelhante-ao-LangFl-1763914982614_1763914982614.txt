Quero que você gere **todo o código** de um **Editor Visual de Agentes de IA**, semelhante ao LangFlow ou n8n, usando:

- Next.js 15
- ReactFlow
- ShadCN (tema dark)
- TailwindCSS
- TypeScript
- Zustand
- API Routes
- Nodes customizados
- Persistência via API no backend
- Modo de execução / trace passo-a-passo

O editor deve me permitir criar e editar graficamente 3 agentes internos do meu SaaS:

- Gerador de Workflow
- Normalizador de Workflow
- Monitor de Gargalos

Cada agente possui seu próprio grafo salvo no backend.

====================================================
🎯 OBJETIVO
====================================================

Criar um editor visual com:

- Canvas baseado em ReactFlow
- Nós arrastáveis (drag-and-drop)
- Conexões com setas (edges)
- Edição completa dentro dos nós
- Preview de execução do agente
- Persistência do grafo no backend
- Ajuste de temperatura por nó
- Teste de nó individual
- Execução completa com trace
- Integração estilo LangGraph Viewer (mock)
- Estilo moderno baseado no LangFlow

O resultado final deve ser um estúdio visual completo para construção de agentes com nós e conexões.

🧩 ESTRUTURA DO EDITOR
====================================================

Criar página:

/agents/studio/[agentId]

Componentes obrigatórios:

1. Canvas.tsx  
   - ReactFlow  
   - Minimapa  
   - Controles

3. Toolbar.tsx

   - Undo / Redo

4. ExecutionPanel.tsx  
   - Logs  
   - Trace por etapa

====================================================
🧱 TIPOS DE NÓS (IMPLEMENTAR TODOS)
====================================================

1. PromptNode
   Campos:
   - Título
   - Campo “system prompt”
   - Slider de Temperatura (0 a 2)
   - Campo max tokens
   - Botão “Testar nó”
   - Uma saída

2. LogicNode
   Campos:
   - Nome da etapa
   - Tipo de lógica (select):
     - Filtro
     - Roteamento
     - Normalização
     - Validação
     - Chamada de ferramenta
   - Campo “condição”
   - Botão “Testar lógica”
   - Entrada e saída

3. OutputNode
   Campos:
   - Nome da saída
   - Campo Schema JSON
   - Botão: Executar Workflow
   - Entrada única

Todos os nós devem ser implementados como **nós customizados ReactFlow**, usando componentes ShadCN.

====================================================
📡 PERSISTÊNCIA NO BACKEND
====================================================

Criar rota:

POST /api/agents/save

Recebe:
{
  "agentId": "workflow-generator",
  "graph": {
    "nodes": [],
    "edges": [],
    "viewport": {}
  }
}

Salva o conteúdo em:

/data/agents/<agentId>.json

Criar rota:

GET /api/agents/load?agentId=<id>

Retorna o grafo salvo.

====================================================
⚙️ EXECUÇÃO DO AGENTE
====================================================

Criar rota:

POST /api/agents/execute

O backend deve:

1. Ler o grafo completo do agente  
2. Percorrer os nós na ordem das conexões  
3. Simular execução de cada etapa  
4. Gerar trace com logs  
5. Retornar:  
   - logs  
   - passos  
   - input  
   - output  
   - tokens (mock)  
   - latência (mock)  

Simular execução — NÃO use LLM real.
