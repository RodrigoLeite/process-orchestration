Quero que você gere **todo o código** necessário para implementar:

### **1. Infra de Inngest**

- configuração do cliente no backend

### **2. Registro de Functions (Workers)**
Crie workers para processar:

- **generate_workflow** → executa meu AGENTE GERADOR DE WORKFLOW  
- **normalize_workflow** → executa o AGENTE NORMALIZADOR DE WORKFLOW  
- **assign_workflow** → executa o AGENTE ATRIBUIDOR DE WORKFLOW  

Cada um deve:  
1. receber o payload (tenant_id, user_id, demand_id, prompt)  
2. buscar dados no banco via Drizzle  
3. executar sua lógica  
4. salvar outputs em tabelas appropriadas  
5. emitir eventos para o frontend via pusher (se possível)  
6. retornar status final do job

### **3. Rotas API Express**
Crie rotas como:

`POST /api/agents/workflow/generate`
- valida tenant_id
- cria o job usando `inngest.send()`
- retorna jobId / eventId

`POST /api/agents/workflow/normalize`

`POST /api/agents/workflow/assign`

### **4. Modelo de Job Execution no DB**
Quero schemas Drizzle (PostgreSQL) como:

```
jobs
- id (pk)
- tenant_id (fk)
- user_id
- agent_type (enum)
- payload (jsonb)
- status (pending, running, completed, failed)
- output (jsonb)
- error (text)
- created_at
- updated_at
```

### **5. Workers com Retry, Rate-Limit e Concurrency**
Cada worker deve incluir:

```
export const generateWorkflowFn = inngest.createFunction(
  { id: "generate-workflow", concurrency: 5, retries: 3 },
  { event: "agent/generate.workflow" },
  async ({ event, step }) => { ... }
)
```

### **6. Execução dos Agentes**
Os workers irão chamar meus 3 agentes internos como módulos:

```
import { runGeneratorAgent } from "@/agents/generator";
import { runNormalizerAgent } from "@/agents/normalizer";
import { runAssignmentAgent } from "@/agents/assigner";
```

Cada worker deve:

1. carregar os dados no banco  
2. chamar o agente correspondente  
3. salvar resultado  
4. marcar status  
5. disparar webhook opcional  
6. emitir evento realtime (opcional)
